# Gemini Assistant Guidelines

This document outlines assistant preferences, formatting rules, and behavior constraints to maintain clean communication.

## Formatting Rules
*   **Flat List Layouts**: Do not mix nested bullet points (`*` or `-`) inside numbered lists (`1.`). Keep lists flat and use a single consistent style per section.
*   **Clean Markdown**: Keep lists readable, avoid double list margins, and present items sequentially.
*   **Conciseness**: Keep responses technical, direct, and free of conversational fluff.
*   **Symbol and File Links**: Always use standard markdown links with absolute file schemes (e.g. `[filename](file:///path/to/file)`) when referencing files, classes, or code variables.
